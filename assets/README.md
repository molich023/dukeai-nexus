# DukeAI Nexus — Repository Assets

This directory contains shared, repository-level visual assets for DukeAI Nexus.

## Contents

- `brand/dukeai-nexus-logo.svg` — horizontal project wordmark.
- `brand/dukeai-nexus-mark.svg` — standalone project mark.
- `brand/favicon.svg` — compact browser/app icon.
- `diagrams/dukeai-nexus-retrieval-flow.svg` — overview of the current retrieval prototype.

## Usage

These files are source SVG assets and can be viewed in a browser or edited with a vector graphics editor. They may be referenced from the repository README, project documentation, presentations, or other project materials.

## Relationship to `website/assets/`

This top-level `assets/` directory is for shared project assets. It is separate from `website/assets/`, which contains files used directly by the static website. Do not replace or merge the website directory when adding these files.

## Accuracy note

The retrieval-flow diagram describes the current retrieval-oriented prototype: document ingestion and metadata handling, text processing, lexical retrieval/ranking, and source passages. It does not depict a deployed language model, translation engine, autonomous agent, or production service.

## Asset status

These are initial project identity and documentation assets. Review them before using them in an official release or external publication.
