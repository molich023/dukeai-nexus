JOIN THE PROJECT

Help build carefully, openly, and together.

Contributions are welcome in software development, testing, documentation, language research, accessibility, and responsible data governance.

Ways to contribute

  • C++ development and bug fixes.
  • Testing on Android Termux and Linux.
  • Documentation and reproducible examples.
  • English and Kiswahili linguistic review.
  • Research into African languages and dialects.
  • Retrieval evaluation and benchmarking.
  • Accessibility and user-interface research.

Before submitting

  1. Read the repository README and contribution guidelines.
  2. Check existing issues and pull requests.
  3. Keep changes focused and explain their purpose.
  4. Add or update tests where appropriate.
  5. Report the platform and test results.
  6. Document limitations and new dependencies.

Data and cultural responsibility

Do not submit books, datasets, recordings, translations, images, or cultural materials unless you have the right to share them. Public availability is not proof of redistribution or model-training permission. Respect consent, attribution, community protocols, and restricted knowledge.

Contribute on GitHub

Use the repository's issue tracker and pull-request process once the public repository is available.
