PRIVACY & DATA

Local-first principles. Clear limits.

DukeAI Nexus is designed around local document processing and privacy-conscious development. This page describes project principles, not a certification or guarantee of security.

Current prototype

The current C++ prototype loads and processes local documents for retrieval. Its intended workflow is local to the device. It is not currently a hosted chatbot that sends documents to an AI inference service.

The public website is a static information site. Its hosting provider may process ordinary connection data such as IP addresses and request logs under that provider's policies. Review the hosting provider's terms and privacy documentation before deployment.

Documents and rights

Users and contributors are responsible for ensuring they have permission to use documents they add. A document being publicly accessible does not automatically permit copying, redistribution, translation, or model training.

Private research materials, personal information, credentials, and unapproved datasets should not be committed to the public repository.

Future network features

If future versions introduce network-connected services, the project should document what information is transmitted, why it is needed, who receives it, how long it is retained, and how users can disable the feature.

Security limitations

The prototype has not been independently security-certified. Users should not treat it as a secure storage system or assume that local files are protected against every form of unauthorised access.

Questions and corrections

For project-related privacy or data-governance concerns, use the repository's available GitHub contact or issue facilities. Do not post private personal information or security-sensitive details in public issues.
