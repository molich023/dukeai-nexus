IMPLEMENTATION STATUS

What works today — and what does not.

DukeAI Nexus currently has a working C++17 research prototype. This page intentionally distinguishes implemented components from proposed research.

Implemented components

Document loading

Local plain-text loading with bounded reads and basic file checks.

Metadata validation

Structured JSON metadata with validation and source consistency checks.

Text processing

Basic tokenisation and feature extraction. Current tokenisation is not full Unicode or language-specific processing.

Lexical retrieval

Paragraph-based candidate selection using query-term and title overlap, language-tag matching, and deterministic ordering.

Energy-ranker component

A linear component with pairwise margin-training support, tested using a synthetic fixture. The demo uses an untrained ranker and deterministic fallback.

Tests and demonstration

CMake/CTest automated tests and an English/Kiswahili retrieval demonstration.

Not implemented

  • Natural-language answer generation or chatbot conversations.
  • Machine translation.
  • Semantic or vector retrieval.
  • Full African language and dialect processing.
  • Speech or multimodal capabilities.
  • JEPA or world-model implementation.
  • Production Android or Linux graphical interfaces.

Important retrieval limitation

The demonstration retrieves source passages. These passages are not generated answers and should be checked against their original documents. The current ranker has not demonstrated real-world ranking improvements.
