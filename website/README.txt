DukeAI Nexus website

Contents:
- HTML pages at the website root
- assets/css/style.css
- assets/js/main.js
- assets/images/favicon.svg

Deployment:
- Configure Cloudflare Pages with website/ as the root directory.
- Framework preset: None
- Build command: leave empty (or use a no-op if the dashboard requires one)
- Build output directory: .

The site is static HTML/CSS/JavaScript and has no build dependencies.

Before public deployment:
1. Confirm the GitHub repository is public and the referenced documentation files exist.
2. Confirm the project status and installation commands match the current source.
3. Review the hosting provider's privacy/logging terms.
4. Replace or supplement the text-only brand mark with approved original brand artwork when ready.

The assets/images directory includes a simple original SVG favicon. No third-party images or tracking scripts are included.
