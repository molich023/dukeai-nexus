LOCAL BUILD

Build DukeAI Nexus on your device.

The current release path is to clone the source repository and build the C++ prototype locally. There is no prebuilt Android app or browser-based AI service at this stage.

1. Get the source

git clone https://github.com/molich023/dukeai-nexus.git
cd dukeai-nexus

If the repository has not yet been made public, this clone command will not work for visitors until publication is complete.

2. Android (Termux)

Install Termux, update packages, and install the build dependencies:

pkg update
pkg upgrade
pkg install git clang cmake pkg-config jsoncpp

3. Linux (Debian/Ubuntu example)

Install the compiler, CMake, pkg-config, JsonCpp development headers, and Git:

sudo apt update
sudo apt install git build-essential cmake pkg-config libjsoncpp-dev

Package names and availability may vary by Linux distribution.

4. Configure and build

cmake -S . -B build
cmake --build build

5. Run tests

ctest --test-dir build --output-on-failure

6. Run the demonstration

./build/dukeai_demo data/demo

The demo retrieves existing English and Kiswahili water-conservation passages. Retrieved passages are source text, not generated answers.

Before you begin

Build and test results should be checked on your own device. The current prototype is a research tool, not a production-ready AI assistant. See the implementation status and documentation.
