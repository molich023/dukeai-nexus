DukeAI Nexus                                                                                              **An offline-first, open-source African AI research project.**                                                                                                    DukeAI Nexus is being developed as a local knowledge assistant,                                             initially focused on English and Kiswahili civic and scientific                                             learning.                                                                                                   The project targets Android (Termux) and Linux, with an emphasis                                            on privacy, source traceability, responsible data governance,                                               and resource-aware development.                                                                             ## Current status                                                                                           DukeAI Nexus currently has a working C++17 research prototype.                                                                                                    Implemented components:                                                                                     - Linear energy-ranker component with pairwise margin-training support, tested using a synthetic fixture.   - Basic text tokenisation and feature extraction.     - Local plain-text document loading.                  - Structured JSON document metadata.                  - Metadata validation and source consistency checks.  - Paragraph-based lexical retrieval with deterministic ranking; the current demonstration uses an untrained ranker.                                               - Source and file provenance preservation.            - Unified document ingestion.                         - Standalone English and Kiswahili retrieval demonstration.                                                 - Automated tests using CMake and CTest.                                                                    This is not yet a general-purpose AI assistant. Natural-language                                            generation, translation, semantic retrieval, and JEPA are not                                               implemented.                                                                                                ## Requirements                                                                                             -
